Modèles de sana24

Outre le modèle standard avec libre choix du médecin, sana24 propose en 2027 ces tarifs (pas tous dans chaque canton). Les prestations sont les mêmes dans tous les modèles, seul le premier interlocuteur change.

  • Alternatif: Combi Care
  • HMO: Managed Care, Managed Care ohne Capitation, VIVA - Gesundheitsplan
  • Médecin de famille: Med Direct
  • Telmed: Med Call, Tel Care, Tel Doc
